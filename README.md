### Descrição 

 1. **Sobre o projeto**

     - Távola Quadrada é um projeto baseado no projeto já existente: Tavola Redonda, sendo destinado ao público de pessoas que jogam RPG (Roleplay gaming), é uma alternativa mais fácil e pratica para a criação de mesas e personagens para os jogadores, reunindo alguns sistemas, facilitando assim o decorrer de criação pre-campanha, que costuma ser a parte mais demorada de um RPG.

     - Diferente do projeto original, A linguagem escolhida para desenvolver a távola quadrada, foi Django, sendo desenvolvido exclusivamente para fins de trabalho universitario valendo nota na disciplina.
